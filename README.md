# Little Brush Games website

Static playful game website for **Little Brush Games** and **Truth Or Mole**. Built as plain HTML/CSS for GitHub Pages, with generated hero/mascot assets in `assets/`, real app screenshots in `assets/screenshots/`, and party-game landing patterns (at-a-glance specs, how-to-play loop, gameplay screenshots, content packs, FAQ).

## Local preview

```bash
python3 -m http.server 8765
```

Then open <http://127.0.0.1:8765>.

## GitHub Pages

Use `Deploy from a branch`, branch `main`, folder `/root`.

The repository includes `CNAME` for:

```text
littlebrushgames.com
```

Legal documents live separately at <https://legal.littlebrushgames.com/>.
